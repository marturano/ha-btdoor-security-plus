# Target Execution Checklist

Use this checklist on a supported Home Assistant 2026.x instance.

## Runtime

- clean installation;
- integration setup duration;
- restart and reload;
- idle and workload CPU/RAM;
- event latency;
- 24-hour stability.

## Compatibility

- update from previous supported release;
- entity and device continuity;
- diagnostics and support bundle;
- rollback.

## HACS and GitHub

- repository validation;
- HACS clean install;
- HACS update;
- release tag, ZIP and checksum;
- rollback asset.

## Security

- no credentials in logs or diagnostics;
- secret storage verified;
- network exposure reviewed;
- dependencies reviewed.

## UX and accessibility

- dashboard rendering;
- labels and translations;
- keyboard navigation;
- screen-reader behavior;
- contrast and icon clarity.
