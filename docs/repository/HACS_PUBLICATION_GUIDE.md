# HACS Publication Guide

Before every Final Release:

1. validate repository and integration structure;
2. validate `hacs.json`, `manifest.json`, brands assets and metadata;
3. create a version-matching tag and GitHub Release;
4. verify the release archive can be downloaded and installed;
5. test clean HACS installation, upgrade from the previous supported version, restart, removal and reinstall;
6. record HACS validation output and any warnings;
7. verify documentation and issue links;
8. publish only after Release Readiness approval.
