# Definition of Done

A change is done only when all applicable items are complete:

- implementation and self review;
- code, test, UX and accessibility quality reviews with evidence;
- static analysis and linting;
- unit, integration and regression test layers, each executed or explicitly classified;
- security review and policy update;
- performance review and reproducible benchmark comparison;
- translations validated and Translation Review updated;
- compatibility verified and compatibility matrix updated;
- full project documentation reviewed;
- automation, blueprint, Lovelace, script, template and package guides updated when applicable;
- Engineering Notebook updated;
- CHANGELOG and release documentation updated;
- QA passed;
- Validation Maintenance and Update completed, with canonical report and register current;
- Project Health Dashboard regenerated from canonical evidence;
- every applicable workflow gate has a documented decision;
- Release Readiness and Publication gates passed;
- handoff fully replaced and current;
- Final Release only: GitHub and HACS publication lifecycle validated and documented.
