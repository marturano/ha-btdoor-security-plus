# Engineering Notebook Policy

`ENGINEERING_NOTEBOOK.md` is the chronological technical record. Update it during work and at release closure with hypotheses, experiments, implementation notes, failures, root causes, workarounds, measurements, test outcomes and future observations.

Do not duplicate roadmap, ADR, CHANGELOG or handoff content. Link to them when necessary.

## 2026-07-22 — Gate workflow and Project Health Dashboard

Adopted formal workflow gates and a generated evidence-based health dashboard. Initial Final-readiness blockers are measured benchmarks, Final security evidence, runtime compatibility and HACS/GitHub publication validation.
