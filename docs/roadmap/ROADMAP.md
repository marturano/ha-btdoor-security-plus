## Versioning rule

- 1.x validates the access, media, call, camera, notification and AI-vision domains.
- 2.x expands the validated model to the complete BTicino/Netatmo ecosystem.
- 3.x publishes the SDK and extension framework after the domain model is mature.
- 4.x provides cross-domain intelligence.
- 5.x provides enterprise, fleet and installer capabilities.

## Quality Scale policy

All roadmap series must preserve Home Assistant Integration Quality Scale **Gold**. Gold is the release minimum, desired tier and maximum governed tier. Platinum work is not part of the roadmap unless explicitly introduced by a future ADR; existing Platinum audit material remains historical analysis only.
