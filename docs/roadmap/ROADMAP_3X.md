# Roadmap 3.x — Developer Platform

## 3.0 — SDK Foundation
Python, Event, Adapter, Media, Voice, Notification, Diagnostics, Timeline, Dashboard, Blueprint, Automation, REST and WebSocket SDKs plus schemas and CLI.

## 3.1 — Extension Framework
Lifecycle and provider contracts for adapters, AI, vision, voice, notifications, media, discovery, certificates, cloud, storage, analytics and identity; capability negotiation, permission model, isolation and compatibility checks.

## 3.2 — Developer Experience
Scaffolding, examples, cookbook, API Explorer, mock runtime, simulator, protocol replay, HACS/Git workflows, contract tests and Compatibility Lab.

## 3.3 — AI Provider Platform
OpenAI, Anthropic Claude, Google Gemini, Amazon Rekognition, Ollama, LM Studio, Azure OpenAI, Vertex AI, Mistral and OpenRouter through common provider contracts.

## 3.4 — Open Automation Platform
REST, WebSocket, MQTT, event streams, webhooks, Node-RED, AppDaemon, PyScript, n8n and MCP integrations.

## 3.5 — Marketplace & Governance
Extension registry, signatures, compatibility metadata, dependencies, release channels, revocation, review, HACS distribution and community governance.

## 3.6 — Trust & Observability Tooling
SDK-level telemetry, provider health, OpenTelemetry/Prometheus hooks, signed packages, supply-chain validation and extension diagnostics.

## 3.7 — Repository Automation & Governance

CI-enforced Repository Integrity Suite, roadmap/documentation/ADR/translation/handoff checks, release completeness, documentation publication pipelines, governance reports, and reproducible release packaging.
