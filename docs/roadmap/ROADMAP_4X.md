# Roadmap 4.x — Intelligent Whole-Home Platform

## 4.0 — Cross-Ecosystem Intelligence
Contextual orchestration across access, security, climate, environment and energy; explainable automations; occupancy intelligence; predictive maintenance; local/cloud AI policies.

## 4.1 — Advanced Energy Orchestration
Photovoltaics, storage, EV charging, flexible loads, dynamic tariffs, peak shaving, forecasting and optimization.

## 4.2 — Safety, Health & Accessibility
Smoke/CO and environmental anomaly workflows, vulnerable-user profiles, visual/haptic alerts, caregiver escalation, emergency mode and privacy controls.

## 4.3 — Adaptive Home Experience
Behavior-aware scenes, dynamic comfort, personalized notification policies and transparent user override.

## 4.4 — Documentation Platform

**Goal:** publish a versioned, searchable, multilingual documentation experience without changing the repository-first source of truth.

Planned scope:
- MkDocs Material or an equivalent static documentation system;
- generated navigation, Mermaid, full-text search, versioned releases, and GitHub Pages;
- offline bundle and optional PDF export;
- automated API/reference extraction and link validation;
- documentation analytics that do not expose household or user data;
- semantic search as a later, privacy-reviewed extension.

This milestone is planned, not implemented by RC.15. The Markdown repository remains canonical.
