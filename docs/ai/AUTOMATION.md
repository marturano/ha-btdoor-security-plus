# AI Automation Integration

## Target surfaces

- Home Assistant services and service responses;
- scripts and automations;
- Assist and conversation flows;
- dashboards and blueprints;
- notifications and timeline events.

Target service names such as `btdoor.ai_vision` are architectural examples, not RC.15 runtime claims. Automation actions must specify capability, source, policy profile and optional fallback behavior.

Security-sensitive actions require explicit authorization checks after AI processing.
