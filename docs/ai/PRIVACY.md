# AI Privacy and Governance

## Principles

- data minimization;
- local-first preference;
- purpose limitation;
- explicit consent for cloud camera/audio processing;
- separate consent for biometric identity;
- auditable provider selection;
- redacted logs and support bundles;
- configurable export and deletion.

## Classification
Requests are classified as public, household context, personal data, personal media, biometric data or secret. Policies define eligible providers, retention, caching and fallback for each class.

A fallback may only reduce capability; it may never weaken the privacy classification.
