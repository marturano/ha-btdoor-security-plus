# Aan de slag

## Installatie
Installeer BTDoor Security+ via HACS als aangepaste repository of kopieer `custom_components/btdoor_security_plus` naar de Home Assistant-configuratie. Herstart Home Assistant en kies onder **Instellingen → Apparaten & diensten → Integratie toevoegen** BTDoor Security+.

## Configuratie
Gebruik het door de eigenaar geautoriseerde MyHomeWeb-account van de officiële Door Entry-app. Selecteer de juiste gateway en voltooi de SIP-provisioning. Kopieer geen identiteiten, certificaten of aanmeldgegevens uit een andere installatie.

## Eerste controle
Controleer dat gateway en logische apparaten maar één keer verschijnen. Controleer Cloud en SIP en gebruik `button.apri_cancello` alleen wanneer fysieke bediening veilig is. Setup, reload en herstart mogen de poort nooit automatisch openen. Support Bundles blijven privé.
