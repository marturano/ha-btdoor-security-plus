# Developer Console en diagnose

Schakel Developer Mode en geavanceerde diagnose alleen in bij probleemonderzoek. Dashboards worden via de manager gegenereerd zodat stabiele ID’s voor de gekozen entry worden opgelost.

Hulpmiddelen omvatten Runtime Inspector, Event Monitor, statistieken, zelftests en supportrapporten. Tests mogen de poort niet openen. Logboeken en rapporten kunnen na opschoning operationele metadata bevatten; houd ze privé en verwijder ze wanneer ze niet meer nodig zijn.

Het Support Bundle exporteert genormaliseerd runtime- en registerbewijs en verwijdert geheimen, privésleutels, absolute paden en gevoelige mediagegevens. Opschonen behoudt configuratie en certificaten.
