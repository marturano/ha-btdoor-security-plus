# Compatibiliteit

BTDoor Security+ richt zich op **Home Assistant Core 2026.x**. Home Assistant 2026.7.x is de primaire eindvalidatieomgeving; een minimumversie geldt pas na geslaagde controles. Alleen importeren bewijst geen runtimecompatibiliteit.

Compilatie, automatische tests, Home Assistant-runtime, fysieke gateway, Alexa en Google Assistant zijn afzonderlijke bewijssoorten. Schone installatie, upgrade, setup, reload, unload, herstart, registeridentiteit en multi-entry-isolatie zijn verplicht voor Stable.

Alexa heeft echte validatie. Google Assistant wordt ondersteund via Home Assistant-entiteitsblootstelling, maar is nog niet geverifieerd.
