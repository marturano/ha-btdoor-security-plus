# Documentation Scope Matrix

| Change type | Required updates |
|---|---|
| Runtime behavior | README, architecture, API, examples, changelog, release notes, handoff |
| Entity/service/event contract | API, compatibility, voice assistants, tests, translations, handoff |
| Architecture decision | ADR, architecture, roadmap if applicable, Project Memory, handoff |
| New device family | Ecosystem docs, compatibility matrix, entity model, roadmap, translations |
| AI provider/capability | AI docs, privacy, security, API, compatibility, roadmap |
| Release | Version, changelog, release notes, validation, translation status, PCP, checksum |
| Documentation replacement | Archive copy, pointer, documentation changelog, manifest |
