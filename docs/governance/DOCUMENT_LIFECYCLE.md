# Document Lifecycle

## States

`Active → Deprecated → Archived`

Deletion is permitted only for transient, generated, sensitive, or invalid files that have no historical value. Normative documentation is archived rather than silently deleted.

## Required archive metadata

Every archived normative document must identify its archive release, reason, replacement, and original path. The documentation changelog records the move.

## Review triggers

Review documentation whenever runtime behavior, entity contracts, services, event schemas, compatibility, security boundaries, roadmap scope, installation, translations, dashboards, blueprints, or release procedures change.
