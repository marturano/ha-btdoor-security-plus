# BTDoor Security+ — English

This documentation covers the canonical **1.0 Foundation** and **1.1 Core Stable** product line. Start with installation, then review dashboards, voice assistants and compatibility. Engineering documents in `docs/architecture`, `docs/adr` and `docs/engineering` are normative in English.

## User guides
- `user/getting-started.md` — installation, first setup and safe verification.
- `user/dashboards-and-blueprints.md` — generated dashboards, entity resolution and blueprints.
- `voice_assistants.md` — optional Alexa and Google Assistant bridge.
- `developer_console.md` — advanced diagnostics and private support artifacts.
- `release/compatibility.md` — Home Assistant 2026.x support and evidence levels.

The native gate action is `button.apri_cancello`. The optional voice switch is a momentary command bridge, not a representation of gate state.
