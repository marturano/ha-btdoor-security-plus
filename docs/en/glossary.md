# Glossary

- **Gateway:** configured Door Entry gateway and root runtime device.
- **Config entry:** one Home Assistant configuration instance, isolated from every other gateway.
- **Logical device:** Home Assistant device grouping for Cloud, SIP, calls, media or diagnostics.
- **Native gate button:** explicit `button` entity that sends one gate-opening command.
- **Voice bridge:** optional momentary switch exposed to Alexa or Google Assistant on a separate virtual device.
- **Dispatcher:** per-entry mechanism that distributes normalized runtime updates.
- **Support Bundle:** private, sanitized diagnostic ZIP generated for troubleshooting.
- **Runtime validation:** actual setup, reload, unload and restart testing in Home Assistant.
- **Real-device validation:** evidence collected with a physical gateway.
- **Historical provenance:** archived development material retained without defining current versioning.
