# Compatibilità

BTDoor Security+ è destinato a **Home Assistant Core 2026.x**. Home Assistant 2026.7.x è l’ambiente principale di validazione finale; la versione minima 2026.x viene accettata solo dopo il superamento dei relativi gate. Il solo import del codice non dimostra la compatibilità runtime.

Le evidenze sono separate tra compilazione, test automatici, runtime Home Assistant, gateway fisico, Alexa e Google Assistant. Installazione pulita, upgrade supportato, setup, reload, unload, riavvio, identità del registry e isolamento multi-entry sono gate obbligatori per la Stable.

Alexa dispone di evidenza reale di scoperta e funzionamento. Google Assistant è supportato architetturalmente tramite l’esposizione delle entità Home Assistant, ma è attualmente indicato come non verificato.
