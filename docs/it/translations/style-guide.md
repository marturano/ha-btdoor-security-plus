# Guida di stile per le traduzioni

La documentazione tecnica inglese è normativa. Guide utente e stringhe Home Assistant sono mantenute in inglese, italiano, francese, tedesco, spagnolo e olandese. Conserva entity ID, nomi dei servizi, codice, placeholder come `{entry_title}`, nomi di prodotto e acronimi di protocollo.

Traduci il significato, non l’ordine delle parole. Usa la terminologia di `docs/shared/terminology.yaml` ed evita di mescolare lingue nella stessa frase. I termini tecnici possono rimanere invariati solo quando sono nomi standard di interfaccia o protocollo.

Ogni lingua deve avere la stessa struttura di chiavi JSON e gli stessi placeholder di `strings.json`. Una traduzione non deve dichiarare validazioni o compatibilità assenti dalla sorgente inglese.
