# Developer Console e diagnostica

Abilita Developer Mode e Diagnostica avanzata solo durante la risoluzione dei problemi. Developer Console e dashboard Runtime vengono generate dal gestore dashboard, che risolve gli unique ID stabili per la config entry scelta.

Gli strumenti includono Runtime Inspector, Event Monitor, metriche eventi, self-test e controlli per i report. I test non devono aprire il cancello. Log e report possono contenere metadati operativi anche dopo la sanitizzazione: conservali privatamente ed eliminali quando non servono più.

Il Support Bundle esporta evidenze normalizzate di runtime, entità e Device Registry rimuovendo segreti, chiavi private, percorsi assoluti e dati multimediali sensibili. **Pulisci ambiente di debug** conserva configurazione e certificati.
