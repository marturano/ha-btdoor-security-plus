# Benchmark Baselines

No authoritative performance baseline is declared by this governance-only package. The next implementation/release cycle must establish measured baselines using the scenarios in this directory before performance claims are made.

## Baseline metric catalogue

The first measured baseline must cover, where applicable: setup, reload, unload and restart duration; event-loop blocking; memory; gateway count; call-control latency; media throughput; AI request latency; provider failure recovery; and support-bundle generation time.
