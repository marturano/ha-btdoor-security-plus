# Ecosystem Model

```text
Platform
└── Home
    ├── Site / Building
    ├── Area
    │   └── Room
    │       ├── Access
    │       ├── Security
    │       ├── Lighting
    │       ├── Energy
    │       ├── Climate
    │       ├── Environment
    │       └── Media
    └── Gateway / Account / Cloud boundary
```

Every physical or virtual device is represented through stable capabilities. Vendor identifiers remain adapter metadata and do not define the public domain model.

Core relationships include source device, logical room, owning home, transport boundary, provider, permissions, privacy policy and correlated events.
