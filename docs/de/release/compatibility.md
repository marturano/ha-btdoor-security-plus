# Kompatibilität

BTDoor Security+ zielt auf **Home Assistant Core 2026.x**. Home Assistant 2026.7.x ist die primäre Abschlussumgebung; eine Mindestversion gilt erst nach bestandenen Prüfungen. Ein erfolgreicher Import beweist keine Runtime-Kompatibilität.

Kompilierung, automatische Tests, Home-Assistant-Runtime, physisches Gateway, Alexa und Google Assistant sind getrennte Nachweise. Saubere Installation, Upgrade, Setup, Reload, Unload, Neustart, Registry-Identität und Multi-Entry-Isolation sind Stable-Pflichten.

Alexa ist real validiert. Google Assistant wird über die Home-Assistant-Entitätsfreigabe unterstützt, ist jedoch noch nicht verifiziert.
