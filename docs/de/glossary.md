# Glossar

- **Gateway:** konfiguriertes Door-Entry-Gerät und Runtime-Wurzel.
- **Konfigurationseintrag:** eine von anderen Gateways isolierte Home-Assistant-Instanz.
- **Logisches Gerät:** Gruppierung für Cloud, SIP, Anrufe, Medien oder Diagnose.
- **Nativer Tortaster:** `button`-Entität für genau einen Öffnungsbefehl.
- **Sprach-Bridge:** optionaler momentaner Schalter auf einem separaten virtuellen Gerät.
- **Dispatcher:** verteilt normalisierte Updates je Eintrag.
- **Support Bundle:** privates, bereinigtes Diagnose-ZIP.
- **Runtime-Validierung:** reale Setup-, Reload-, Unload- und Neustarttests.
- **Gerätevalidierung:** Nachweis mit einem physischen Gateway.
- **Historische Herkunft:** archivierte Entwicklung, die nicht die aktuelle Version definiert.
