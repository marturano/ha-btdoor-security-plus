# Developer Console und Diagnose

Aktivieren Sie Developer Mode und erweiterte Diagnose nur zur Fehlersuche. Die Dashboards werden über den Manager erzeugt, damit stabile IDs des gewählten Eintrags aufgelöst werden.

Werkzeuge umfassen Runtime Inspector, Event Monitor, Metriken, Selbsttests und Supportberichte. Tests dürfen das Tor nicht öffnen. Protokolle und Berichte können trotz Bereinigung Betriebsmetadaten enthalten; behandeln und löschen Sie sie vertraulich.

Das Support Bundle exportiert normalisierte Runtime- und Registry-Nachweise und entfernt Geheimnisse, private Schlüssel, absolute Pfade und sensible Mediendaten. Die Bereinigung erhält Konfiguration und Zertifikate.
