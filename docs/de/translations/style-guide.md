# Übersetzungsleitfaden

Die englische Technikdokumentation ist verbindlich. Benutzerhandbücher und Home-Assistant-Zeichenketten werden auf Englisch, Italienisch, Französisch, Deutsch, Spanisch und Niederländisch gepflegt. Entitäts-IDs, Dienste, Code, Platzhalter wie `{entry_title}`, Produktnamen und Protokollkürzel bleiben erhalten.

Übersetzen Sie die Bedeutung und vermeiden Sie Sprachmischung. Technische Begriffe bleiben nur als anerkannte Schnittstellen- oder Protokollnamen unverändert.

Jede Sprache muss dieselbe JSON-Struktur und dieselben Platzhalter wie `strings.json` besitzen. Übersetzungen dürfen keine nicht belegte Validierung behaupten.
