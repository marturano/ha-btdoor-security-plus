# Erste Schritte

## Installation
Installieren Sie BTDoor Security+ über HACS als benutzerdefiniertes Repository oder kopieren Sie `custom_components/btdoor_security_plus` in die Home-Assistant-Konfiguration. Starten Sie Home Assistant neu und wählen Sie unter **Einstellungen → Geräte & Dienste → Integration hinzufügen** BTDoor Security+.

## Konfiguration
Verwenden Sie das vom Eigentümer autorisierte MyHomeWeb-Konto der offiziellen Door-Entry-App. Wählen Sie das richtige Gateway und schließen Sie die SIP-Bereitstellung ab. Kopieren Sie keine Identitäten, Zertifikate oder Zugangsdaten aus anderen Installationen.

## Erste Prüfung
Gateway und logische Geräte dürfen nur einmal erscheinen. Prüfen Sie Cloud und SIP und betätigen Sie `button.apri_cancello` nur bei sicherem Betrieb. Setup, Reload und Neustart dürfen das Tor niemals automatisch öffnen. Support Bundles bleiben privat.
