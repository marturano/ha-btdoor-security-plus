# ADR-0068: Quality Scale Silver progress

**Status:** Accepted

## Decision

BTDoor Security+ implements two Silver requirements with executable evidence: centralized availability transition logging and explicit platform parallel-update limits. Test coverage is measured through `pytest-cov` and cannot be marked complete unless total integration coverage exceeds 95%.

## Details

Availability logging is entry-scoped and deduplicated. It logs one transition when SIP becomes unavailable and one recovery transition when connectivity returns. All push-driven entity platforms declare `PARALLEL_UPDATES = 0`, because entity updates do not initiate parallel device I/O.

Coverage evidence is generated by `tools/quality_scale/coverage_gate.py`. The initial measurement is below the Silver threshold, therefore the achieved Quality Scale tier remains Bronze.

## Consequences

Silver is not self-awarded. The remaining blocker is a substantial test-coverage programme across integration modules, with measured evidence regenerated after each increment.
