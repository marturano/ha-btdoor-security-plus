# ADR-0048 — Ecosystem documentation contract

Status: Accepted

## Context

Ecosystem files previously consisted of short product descriptions and could be mistaken for runtime support claims.

## Decision

Every ecosystem document must declare current maturity, runtime truth, target roadmap, capability scope, Home Assistant mapping principles and acceptance dependencies. The support matrix is normative.

## Consequences

Documentation can describe future architecture without overstating implemented support. Integrity checks can detect missing sections and unindexed product families.
