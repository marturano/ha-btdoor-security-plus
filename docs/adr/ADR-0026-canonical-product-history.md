# ADR-0026 — Canonical product history

Status: Accepted for 1.1.0-rc.9.

## Decision
Active documentation presents one product line: 1.0 Foundation followed by 1.1 Core Stable. Experimental 3.x–6.x labels are retained only in archives, test provenance, ADR metadata and Git history.

## Consequence
Features are consolidated by retained architecture, not mechanically renumbered. Exact forensic history remains available without confusing users or future development.
