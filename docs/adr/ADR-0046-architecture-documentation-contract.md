# ADR-0046: Architecture Documentation Contract

**Status:** Accepted  
**Date:** 2026-07-21

## Context

Architecture documents had grown incrementally and did not consistently distinguish implemented behavior from planned platform direction.

## Decision

The repository adopts a canonical architecture index, implementation maps, explicit status labels and blocking Architecture Integrity and Mermaid structural checks.

## Consequences

Architecture-changing work must update the relevant document, ADR when necessary, roadmap, handoff and integrity evidence in the same release.
