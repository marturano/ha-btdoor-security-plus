# 0039 — Repository as Source of Truth

- Status: Accepted
- Date: 2026-07-21
- Release: 1.1.0-rc.14

## Context

Project continuity and documentation quality must survive new conversations, contributors, and release cycles.

## Decision

Critical knowledge must be committed to active documentation, ADR, roadmap, or handoff and never live only in conversation.

## Consequences

Release work increases, but architecture knowledge, history, localization obligations, and recovery become explicit and testable.
