# 0037 — Documentation Refactoring Program

- Status: Accepted
- Date: 2026-07-21
- Release: 1.1.0-rc.14

## Context

Project continuity and documentation quality must survive new conversations, contributors, and release cycles.

## Decision

Adopt DRP 2.0 with canonical indexes, domain documentation, lifecycle states, multilingual release summaries, and validation gates.

## Consequences

Release work increases, but architecture knowledge, history, localization obligations, and recovery become explicit and testable.
