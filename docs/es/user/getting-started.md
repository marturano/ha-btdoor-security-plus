# Primeros pasos

## Instalación
Instala BTDoor Security+ mediante HACS como repositorio personalizado o copia `custom_components/btdoor_security_plus` en la configuración de Home Assistant. Reinicia y abre **Ajustes → Dispositivos y servicios → Añadir integración**.

## Configuración
Usa la cuenta MyHomeWeb autorizada por el propietario y empleada por la aplicación Door Entry oficial. Selecciona el gateway correcto y completa el aprovisionamiento SIP. No copies identidades, certificados ni credenciales de otra instalación.

## Primera verificación
Comprueba que el gateway y los dispositivos lógicos aparezcan una sola vez. Revisa Cloud y SIP y pulsa `button.apri_cancello` únicamente cuando sea seguro accionar la puerta física. La configuración, recarga y reinicio nunca deben abrirla automáticamente. Los Support Bundles siguen siendo privados.
