# Compatibilidad

BTDoor Security+ está dirigido a **Home Assistant Core 2026.x**. Home Assistant 2026.7.x es el entorno principal de validación final; la versión mínima solo se acepta tras superar los controles. Importar el código no demuestra compatibilidad runtime.

Compilación, pruebas automáticas, runtime Home Assistant, gateway físico, Alexa y Google Assistant son evidencias separadas. Instalación limpia, actualización, configuración, recarga, descarga, reinicio, identidad del registro y aislamiento multi-entry son obligatorios antes de Stable.

Alexa tiene validación real. Google Assistant se admite mediante la exposición de entidades Home Assistant, pero sigue sin verificar.
