# BTDoor Security+ 1.1.0-rc.15

RC.15 incorpora gobernanza, controles de integridad del repositorio, protección de identificadores de la hoja de ruta y continuidad. El comportamiento en ejecución no cambia.

## Fase 3 — Base del ecosistema

Se añadieron una matriz de compatibilidad veraz y contratos canónicos para el ecosistema BTicino/Netatmo. Solo las capacidades de BTDoor Security+ figuran como implementadas; los demás adaptadores siguen como base o planificación.

## Phase 4 — AI Platform Foundation

Se añadió una arquitectura de IA independiente del proveedor, límite de privacidad, estrategia local-first y matriz de capacidades validada. Los adaptadores de ejecución siguen planificados.

## Phase 5 — API Foundation

Los contratos públicos de entidades, acciones y eventos de Home Assistant ya están documentados, incluidos los límites de seguridad, versionado y exposición a Alexa/Alexa+ y Google Assistant. REST y WebSocket siguen planificados.
