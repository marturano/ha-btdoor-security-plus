# Asistentes de voz

Activa **Comando de voz rápido para la puerta** para crear `switch.apri_cancello_alexa` en el dispositivo virtual **Alexa / Google Gate Bridge**. El interruptor envía un impulso y vuelve inmediatamente a OFF; no representa el estado de la puerta.

Expón solo este interruptor. Mantén privados el botón nativo, el diagnóstico y las entidades Developer Mode. Usa PIN, confirmación y restricciones domésticas cuando estén disponibles.

Alexa cuenta con validación de usuario real. Google Assistant utiliza el mismo modelo de exposición de Home Assistant, pero permanece sin verificar en una cuenta/dispositivo real hasta registrar la evidencia.
