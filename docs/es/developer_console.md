# Developer Console y diagnóstico

Activa Developer Mode y diagnóstico avanzado solo para investigar problemas. Los paneles se generan mediante el gestor para resolver identificadores estables de la entrada elegida.

Las herramientas incluyen Runtime Inspector, Event Monitor, métricas, autopruebas e informes. Las pruebas no deben abrir la puerta. Los registros e informes pueden contener metadatos operativos incluso después del saneado; mantenlos privados y elimínalos cuando dejen de ser necesarios.

El Support Bundle exporta evidencia normalizada del runtime y registros eliminando secretos, claves privadas, rutas absolutas y datos multimedia sensibles. La limpieza conserva configuración y certificados.
