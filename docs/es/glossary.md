# Glosario

- **Gateway:** equipo Door Entry configurado y raíz del runtime.
- **Entrada de configuración:** instancia Home Assistant aislada de los demás gateways.
- **Dispositivo lógico:** agrupación para Cloud, SIP, llamadas, multimedia o diagnóstico.
- **Botón nativo:** entidad `button` que envía una sola apertura.
- **Puente de voz:** interruptor momentáneo opcional en un dispositivo virtual separado.
- **Dispatcher:** distribuye actualizaciones normalizadas por entrada.
- **Support Bundle:** ZIP privado y saneado para diagnóstico.
- **Validación runtime:** pruebas reales de configuración, recarga, descarga y reinicio.
- **Validación real:** evidencia con un gateway físico.
- **Procedencia histórica:** material archivado que no define la versión actual.
