# Guía de traducción

La documentación técnica inglesa es normativa. Las guías y cadenas Home Assistant se mantienen en inglés, italiano, francés, alemán, español y neerlandés. Conserva IDs de entidad, servicios, código, marcadores como `{entry_title}`, productos y acrónimos.

Traduce el significado, evita mezclar idiomas y usa la terminología compartida. Los términos técnicos solo permanecen sin traducir cuando son nombres estándar de interfaz o protocolo.

Cada idioma debe tener la misma estructura JSON y marcadores que `strings.json`. Ninguna traducción puede afirmar una validación ausente en la fuente inglesa.
