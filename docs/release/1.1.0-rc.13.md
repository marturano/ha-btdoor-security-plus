# BTDoor Security+ 1.1.0-rc.13

Architecture and documentation release.

## Highlights

- Introduces the BTDoor Platform umbrella identity and modular product family.
- Reconstructs the complete roadmap from 1.x through 5.x.
- Restores 1.4 Audio & Call Control, 1.5 Voicemail Center, 1.6 Multimedia Timeline, 1.7 Security Cameras and 1.8 Smart Notifications.
- Adds 1.9 AI Vision & Recognition and moves consolidation to 1.10.
- Makes the complete BTicino/Netatmo ecosystem the 2.x product line.
- Moves SDK and Extension Framework to 3.x.
- Adds ecosystem, AI, SDK, security, performance and governance documentation.
- Adds ADR-0032 through ADR-0036.

No intentional runtime behavior changes are included.
