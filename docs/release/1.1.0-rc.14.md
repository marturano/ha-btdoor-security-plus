# 1.1.0-rc.14 — Documentation Foundation & Repository Refactoring

## Scope

This release implements governance and continuity work only. Runtime behavior is intentionally unchanged except version metadata.

## Delivered

- DRP 2.0, PCP 2.0, Project Execution Contract, Project Memory, Recovery Prompt.
- Canonical project/document indexes and repository policy.
- Complete roadmap navigation with Documentation Platform 4.3.
- Archive traceability and documentation changelog.
- Expanded architecture, API, install, security, performance, compatibility, automation, dashboard, and blueprint documentation.
- Release summaries for all supported documentation locales.
- ADR-0037 through ADR-0041.

## Known limitations

This package does not by itself prove clean install, supported upgrades, Home Assistant lifecycle, Google Assistant/Alexa+ real-device behavior, or the future roadmap capabilities. See validation and PCP.
