# Contribuer

Préservez la sécurité asynchrone, l’isolation par entrée, les identités stables et le nettoyage centralisé. N’effectuez aucune opération bloquante dans la boucle d’événements et aucun accès réseau depuis une propriété d’entité.

Toute modification d’architecture exige un ADR et une entrée dans l’Engineering Notebook. Mettez à jour changelog, preuves de compatibilité et traductions ensemble. Le portail ne doit jamais être commandé pendant la configuration, la migration, le rechargement ou une relance.

La branche 1.1 est réservée à la stabilisation. Toute nouvelle chaîne anglaise doit être ajoutée à toutes les langues avec les mêmes espaces réservés.
