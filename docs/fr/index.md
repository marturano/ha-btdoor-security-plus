# BTDoor Security+ — Français

Cette documentation couvre la ligne canonique **1.0 Foundation** et **1.1 Core Stable**. Commencez par l’installation, puis consultez les tableaux de bord, les assistants vocaux et la compatibilité. Les documents techniques de `docs/architecture`, `docs/adr` et `docs/engineering` sont normatifs en anglais.

## Guides utilisateur
- `user/getting-started.md` — installation, première configuration et vérification sûre.
- `user/dashboards-and-blueprints.md` — tableaux générés, résolution des entités et blueprints.
- `voice_assistants.md` — pont optionnel Alexa/Google Assistant.
- `developer_console.md` — diagnostics avancés et artefacts privés.
- `release/compatibility.md` — prise en charge Home Assistant 2026.x.

L’action native du portail est `button.apri_cancello`. Le commutateur vocal est une commande momentanée, pas un état physique.
