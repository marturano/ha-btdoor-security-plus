# Bien démarrer

## Installation
Installez BTDoor Security+ via HACS comme dépôt personnalisé ou copiez `custom_components/btdoor_security_plus` dans la configuration Home Assistant. Redémarrez, puis ouvrez **Paramètres → Appareils et services → Ajouter une intégration**.

## Configuration
Utilisez le compte MyHomeWeb autorisé par le propriétaire et employé par l’application Door Entry officielle. Sélectionnez la bonne passerelle et terminez le provisionnement SIP. Ne copiez jamais identités, certificats ou identifiants d’une autre installation.

## Première vérification
Vérifiez que la passerelle et les appareils logiques n’apparaissent qu’une fois. Contrôlez Cloud et SIP, puis utilisez `button.apri_cancello` uniquement lorsqu’il est sûr d’actionner le portail. Configuration, rechargement et redémarrage ne doivent jamais l’ouvrir automatiquement. Les Support Bundles restent privés.
