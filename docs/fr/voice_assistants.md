# Assistants vocaux

Activez **Commande vocale rapide du portail** pour créer `switch.apri_cancello_alexa` sur l’appareil virtuel **Alexa / Google Gate Bridge**. Le commutateur envoie une impulsion puis revient immédiatement sur OFF ; il n’indique pas l’état du portail.

N’exposez que ce commutateur. Gardez privés le bouton natif, les diagnostics et les entités Developer Mode. Utilisez un code PIN, une confirmation et des restrictions domestiques lorsqu’ils sont disponibles.

Alexa a été validé par un utilisateur réel. Google Assistant repose sur le même mécanisme d’exposition Home Assistant, mais reste non vérifié sur un compte/appareil réel jusqu’à l’enregistrement d’une preuve.
