# Developer Console et diagnostics

N’activez Developer Mode et les diagnostics avancés que pour le dépannage. Les tableaux sont générés par le gestionnaire afin de résoudre les identifiants stables de l’entrée choisie.

Les outils comprennent Runtime Inspector, Event Monitor, métriques, auto-tests et rapports. Les tests ne doivent jamais ouvrir le portail. Les journaux et rapports peuvent conserver des métadonnées opérationnelles après nettoyage : gardez-les privés puis supprimez-les.

Le Support Bundle exporte des preuves normalisées du runtime et des registres tout en supprimant secrets, clés privées, chemins absolus et données média sensibles. Le nettoyage conserve configuration et certificats.
