# Guide de traduction

La documentation technique anglaise est normative. Les guides utilisateur et chaînes Home Assistant sont maintenus en anglais, italien, français, allemand, espagnol et néerlandais. Conservez identifiants d’entité, services, code, espaces réservés comme `{entry_title}`, noms de produit et acronymes.

Traduisez le sens, évitez de mélanger les langues et utilisez la terminologie partagée. Les termes techniques ne restent inchangés que s’ils sont des noms d’interface ou de protocole reconnus.

Chaque langue doit avoir la même structure JSON et les mêmes espaces réservés que `strings.json`. Aucune traduction ne peut revendiquer une validation absente de la source anglaise.
