# Compatibilité

BTDoor Security+ cible **Home Assistant Core 2026.x**. Home Assistant 2026.7.x est l’environnement principal de validation finale ; la version minimale n’est acceptée qu’après réussite des contrôles. Un simple import ne prouve pas la compatibilité runtime.

Compilation, tests automatiques, runtime Home Assistant, passerelle physique, Alexa et Google Assistant sont des preuves distinctes. Installation propre, mise à niveau, configuration, rechargement, déchargement, redémarrage, identité du registre et isolation multi-entrée sont obligatoires avant Stable.

Alexa possède une validation réelle. Google Assistant est pris en charge par l’exposition des entités Home Assistant mais demeure non vérifié.
