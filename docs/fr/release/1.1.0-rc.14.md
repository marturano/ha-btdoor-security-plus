# Version 1.1.0-rc.14

Cette version introduit la gouvernance complète de la documentation, la traçabilité des archives, l’alignement multilingue et un Project Continuity Package pour reprendre le travail dans une nouvelle conversation.

## Belangrijk / Key points

- Runtime behavior is intentionally unchanged except version metadata.
- The repository is the source of truth.
- Every future package must update documentation, translations, roadmap, ADRs, tests, archive records, and handoff.
- Planned roadmap items are not current support claims.
