# Continuity Checklist

Before packaging or changing conversation, verify:

- [ ] Current release is synchronized in runtime metadata, manifests, release notes, validation, and handoff.
- [ ] Project Manifest and Project Memory are current.
- [ ] Governance and Execution Contract reflect new permanent decisions.
- [ ] Roadmap and ADR indexes are synchronized.
- [ ] Documentation and translations are synchronized.
- [ ] Known issues and technical debt are current.
- [ ] Integrity Suite passes.
- [ ] Recovery Prompt names the current release and exact reading order.
- [ ] Package excludes caches, secrets, support bundles, and bytecode.
- [ ] ZIP checksum is generated after final validation.
